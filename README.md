# Customer Feedback Intelligence

An AI-powered customer feedback analysis system that classifies customer feedback into meaningful business categories and provides confidence scores.

## 🚀 Features

- Customer feedback classification
- Product issue identification
- Feedback categorization
- Confidence score for predictions
- Streamlit dashboard
- Brand and channel-level feedback overview
- Business opportunity identification

## 🛠️ Tech Stack

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Streamlit

## 📊 Dashboard

The Streamlit dashboard provides an overview of customer feedback across different brands, products and channels.
